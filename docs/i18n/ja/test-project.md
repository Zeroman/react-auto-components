# 独立した利用側・テストプロジェクト

[English](../../../test-project/README.md) | [简体中文](../zh-CN/test-project.md) | [繁體中文](../zh-TW/test-project.md) | **日本語** | [한국어](../ko/test-project.md) | [Español](../es/test-project.md) | [Français](../fr/test-project.md) | [Deutsch](../de/test-project.md) | [Português (Brasil)](../pt-BR/test-project.md) | [Русский](../ru/test-project.md)

このプロジェクトはローカル tarball からコンポーネントライブラリをインストールし、独立した依存関係とビルドを使用します。ソースエイリアスは使用しません。

デモではブラウザの言語を自動的に検出し、フォールバックとして英語を使用します。ヘッダーまたはグローバル設定から言語を選択できます。選択内容はリロード後も記憶されます。再びブラウザの言語に従うには「Auto」を選択してください。10 の言語をサポートしています。ページはビューポート全体に表示され、テーブルや長いパネルはそれぞれの領域内でスクロールします。

各サンプルページには**コードを表示**ボタンがあり、ダイアログで実際のソースファイルを開きます。ファイル切り替え・ワンクリックコピー・GitHub リンクに対応します。

リポジトリのルートから `pnpm install --frozen-lockfile` と `pnpm prepare:test-project` を実行し、その後 `pnpm --dir test-project dev` を実行してください。

- `pnpm --dir test-project build`：公開型を検証し、本番用ビルドを作成します。
- `pnpm exec playwright install chromium`：初回使用時にブラウザーをインストールします。
- `pnpm --dir test-project test`：Chromium の操作テストを実行します（ポート 4174 で独立したサーバーを自動起動します）。
- ライブラリ変更後は `pnpm prepare:test-project` を再実行し、コンテンツハッシュ付きの tarball 依存関係を更新してください。

`tests/components.spec.ts` のブラウザーテストは、CRUD、フィールド検証と送信失敗後の再試行、設定の永続化、下書きとフォーカス、ポップオーバー、入れ子のタブ、10,000 行のスクロール、サーバー側ページネーション、展開時の測定、列幅、ダウンロード、モバイルレイアウトをカバーします。スクリーンショットは `test-results/` に保存されます。

残りの高さのデモは **AutoTable → 残りの高さ** タブにあります。従来の URL `http://127.0.0.1:4173/?demo=auto-height` でも同じページを開き、このタブを選択できます。この例では Flex/Grid の切り替え、テーブル上部のコンテンツの追加／削除、テーブルの表示／非表示、ページネーションと行数の変更ができます。`tests/auto-height.spec.ts` はブラウザー内の境界とスクロール領域の高さを測定し、残りスペースのレイアウト、動的なリサイズ、仮想化の復元、固定高さとの互換性を検証します。

ブラウザーテストはポート 4173 の開発デモを再利用せず、ポート 4174 で新しい Vite サーバーを起動します。再パッケージングスクリプトは既存のデモサーバーに通知して新しくインストールしたパッケージを解決させ、古いコンポーネントの使用を防ぎます。

グローバル設定は例のコンテンツから分離され、`src/GlobalSettings.tsx` に実装されています。サイドバーまたは右上のコントロールからパネルを開いてください。レイアウト、密度、ラベル幅、テーマを変更しても、現在の例はマウントされたままです。
