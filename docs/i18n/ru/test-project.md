# Самостоятельный проект-потребитель и тестовый проект

[English](../../../test-project/README.md) | [简体中文](../zh-CN/test-project.md) | [繁體中文](../zh-TW/test-project.md) | [日本語](../ja/test-project.md) | [한국어](../ko/test-project.md) | [Español](../es/test-project.md) | [Français](../fr/test-project.md) | [Deutsch](../de/test-project.md) | [Português (Brasil)](../pt-BR/test-project.md) | **Русский**

Этот проект устанавливает библиотеку компонентов из локального tarball-архива, с независимыми зависимостями и сборками. Псевдонимы исходного кода не используются.

Демо автоматически определяет язык браузера, используя английский в качестве резервного. Выберите язык в шапке или в глобальных настройках; сделанный выбор сохраняется между перезагрузками страницы. Выберите «Авто», чтобы вновь следовать языку браузера. Поддерживается десять языков. Страницы заполняют область просмотра, при этом таблицы и длинные панели прокручиваются внутри собственных областей.

На каждой странице примера есть кнопка **Просмотр кода**: она открывает настоящий исходный файл в диалоге — с вкладками файлов, копированием в один клик и ссылкой на GitHub.

Из корня репозитория выполните `pnpm install --frozen-lockfile` и `pnpm prepare:test-project`, затем `pnpm --dir test-project dev`.

- `pnpm --dir test-project build`: проверить публичные типы и создать производственную сборку.
- `pnpm exec playwright install chromium`: установить браузер при первом использовании.
- `pnpm --dir test-project test`: запустить тесты взаимодействий в Chromium (автоматически запускается отдельный сервер на порту 4174).
- После изменения библиотеки снова выполните `pnpm prepare:test-project`, чтобы обновить зависимость от tarball-архива с хешем содержимого.

Браузерные тесты в `tests/components.spec.ts` охватывают CRUD, валидацию полей и повторные попытки после неудачной отправки, сохранение настроек, черновики и фокус, всплывающие панели, вложенные вкладки, прокрутку 10 000 строк, серверную пагинацию, измерения раскрываемых областей, ширину столбцов, скачивания и мобильную компоновку. Скриншоты сохраняются в `test-results/`.

Демо оставшейся высоты находится на вкладке **AutoTable → Оставшаяся высота**. Старый URL `http://127.0.0.1:4173/?demo=auto-height` открывает ту же страницу и выбирает эту вкладку. Пример позволяет переключать Flex/Grid, добавлять/удалять содержимое над таблицей, показывать/скрывать таблицу и менять пагинацию и количество строк. `tests/auto-height.spec.ts` измеряет границы элементов в браузере и высоту области прокрутки, проверяя компоновку в оставшемся пространстве, динамическое изменение размеров, восстановление виртуализации и совместимость с фиксированной высотой.

Браузерные тесты запускают новый сервер Vite на порту 4174, а не используют демо для разработки на порту 4173. Скрипт повторной упаковки уведомляет существующие демосерверы о необходимости разрешить заново установленный пакет, чтобы избежать устаревших компонентов.

Глобальные настройки отделены от содержимого примеров и реализованы в `src/GlobalSettings.tsx`. Откройте панель через боковую панель или элемент управления справа сверху. Текущий пример остаётся смонтированным при изменении компоновки, плотности, ширины подписей или темы.
