# AutoForm

[English](../../auto-form.md) | [简体中文](../zh-CN/auto-form.md) | [繁體中文](../zh-TW/auto-form.md) | [日本語](../ja/auto-form.md) | [한국어](../ko/auto-form.md) | [Español](../es/auto-form.md) | [Français](../fr/auto-form.md) | [Deutsch](../de/auto-form.md) | [Português (Brasil)](../pt-BR/auto-form.md) | **Русский**

Форма по схеме. `AutoSearch` и `AutoDialog` рисуют `AutoForm`, поэтому эти правила колбэков относятся и к ним.

`Field<T>` — размеченное объединение по `type`. `select` без `options`, скаляр у `daterange` и `match: "between"` на скаляре — ошибки TypeScript. `AnyField` и `unsafeField()` — запасной выход; режим разработки все равно предупреждает. Коды в [errors.md](errors.md).

## Поведение и свойства

| Свойство | Поведение |
| --- | --- |
| `fields` | `readonly Field<T>[]`. Без `type` это текстовое поле. Повторяющийся `name` бросает `RAC-FIELD-DUPLICATE` при монтировании. |
| `value` | Управляемое значение. Если оно отличается от внутреннего состояния, форма копирует его и очищает ошибки. Если родитель игнорирует `onChange`, ввод откатывается. |
| `onSubmit(value)` | Только после проверки. **Отклонение или throw: значения остаются, показывается `error.message`, сброса нет.** |
| `columns` | По умолчанию `2`. `actions` по умолчанию `true`. |
| Подписи | `labelPosition` по умолчанию `"top"`. `labelWidth` по умолчанию `"auto"` (измеряется, не больше 45% ширины поля). |

## Если колбэк бросает

| Колбэк | Результат |
| --- | --- |
| `onSubmit` | Перехватывается. Черновик остается. Сообщение показывается. Сброса нет. |
| `rules` поля | Брошенный текст становится ошибкой этого поля. Следующие правила не выполняются. |
| `onChange` поля | Не перехватывается. Остается прежнее значение. |
| `upload` | Отказ виден под полем, значение не сохраняется. `reset()` прерывает сигнал и отбрасывает поздний результат. |
| Отправка во время загрузки | `validate()` возвращает `false` и не вызывает `onSubmit`. |
| `hidden`, `disabled` или нет доступа | Поле не проверяется, даже если оно `required`. |
| Пустой `required` | `undefined`, `null`, `""` или пустой массив блокируют отправку. |

`handle.validate()` резолвится в `true` или `false`. Не бросает.

## Предусловия

Импортируйте `style.css` один раз. В разработке отсутствие `--auto-text` предупреждает `RAC-CSS-MISSING`. `AutoConfigProvider` необязателен и не монтирует диалоги.
