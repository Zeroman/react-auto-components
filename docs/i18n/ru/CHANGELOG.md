## Ещё не выпущено

- Онлайн-демо теперь показывает реальный исходный код каждого примера в диалоге «Просмотр кода» — с вкладками файлов, копированием в один клик и ссылками на GitHub.
- Компоненты React 19, управляемые схемами: AutoForm, AutoSearchPanel, AutoTable, AutoDialog, AutoPopover, AutoScroll и AutoTabs.
- Глобальные размер и плотность, компоновка подписей форм, сохраняемые настройки таблиц и необязательный экспорт XLSX.
- Проект-потребитель с настоящим tarball-архивом, модульные тесты, проверки типов и тесты взаимодействий в Chromium.
- Лицензия MIT, руководство для участников, GitHub CI, шаблоны Issues, инструкции по настройке учётной записи npm и публикации.
- Английская документация по умолчанию, полные переводы и ссылки переключения языка.

Первый выпуск в npm ещё не опубликован. Окончательное имя пакета зависит от области имён новой зарегистрированной учётной записи сопровождающего.
